# 🚗 CarGram — Rede Social de Carros

Rede social

---

## ▶️ Como rodar

**1. Clone o projeto:**
git clone https://github.com/0001203839-byte/instagram.git
cd instagram

**2. Instale as dependências:**
composer install

**3. Configure o ambiente:**
cp .env.example .env
php artisan key:generate

**4. Inicie o servidor:**
php artisan serve

**5. Acesse no navegador:**
http://127.0.0.1:8000

⚠️ Necessário ter Laragon ou PHP 8.1+ e Composer instalados.
